# ⚗️ 化學益智遊戲實驗室 | Chem Puzzle Lab

一組以化學元素與化合物為主題的網頁益智遊戲，支援手機觸控與電腦鍵鼠操作，無需安裝，開啟瀏覽器即可遊玩。

每次更版的功能、修正與操作變更，請見 [版本更新紀錄](docs/RELEASE_NOTES.md)。

## 遊戲列表

### 🧊 3D 化學魔術方塊

以 Three.js 打造的 3×3×3 魔術方塊，每個面上顯示化學元素符號（H、O、C、Na、Cl、Ca）。透過轉動切片排面，在任意一面的**橫排或直排 3 格**湊齊化學配方即可得分。

**操作方式：**

| 操作 | 手機觸控 | 電腦 |
|------|---------|------|
| 轉動切片排面 | 滑動方塊 | 拖曳方塊 |
| 旋轉觀看視角 | 滑動背景空白處 | 拖曳背景空白處 |
| 正視角 / 復原 / 洗牌 / 配方表 | 底部按鈕 | 底部按鈕 |

**可合成配方（部分）：**

| 配方 | 組合 | 分數 |
|------|------|------|
| H₂O 水分子 | H×2 + O×1 | +150 |
| CO₂ 二氧化碳 | C×1 + O×2 | +150 |
| NaOH 氫氧化鈉 | Na×1 + O×1 + H×1 | +220 |
| O₃ 臭氧 | O×3 | +200 |

合成成功後該 3 格元素會自動刷新，可持續挑戰更高分數。

### 🧪 化學俄羅斯方塊

經典俄羅斯方塊結合化學反應機制。方塊上標示化學元素符號，落地後除了傳統的**滿行消除**外，**上下左右相鄰連通**的原子若符合化學配方，會自動引爆消除並觸發**重力連鎖 Combo**。

**操作方式：**

| 操作 | 手機觸控 | 鍵盤 |
|------|---------|------|
| 左右移動 | 左右滑動棋盤 / 底部 ◀ ▶ 按鈕 | ← → |
| 加速下落 | 下滑棋盤 / ▼ 按鈕 | ↓ |
| 直接落底 | 大幅下滑 / ⏬ 按鈕 | 空白鍵 |
| 旋轉 | 點擊棋盤 / ↻ 按鈕 | ↑ |
| 暫存 (Hold) | 點擊 HOLD 區塊 | C |

**可合成配方（部分）：**

| 配方 | 組合 | 分數 |
|------|------|------|
| H₂O 水 | H×2 + O×1 | +200 |
| CO₂ 二氧化碳 | C×1 + O×2 | +220 |
| NaOH 氫氧化鈉 | Na×1 + O×1 + H×1 | +280 |
| CaCO₃ 碳酸鈣 | Ca×1 + C×1 + O×3 | +450 |
| CH₄ 甲烷 | C×1 + H×4 | +380 |

連鎖反應倍率隨 Combo 次數遞增，策略性地擺放元素方塊可創造高分連鎖。

### ⚔️ 元素獵人

俯視角化學 ARPG。入門探索可跟著小地圖的金色標記，收集 H、O，合成 H₂O 並通過守衛；入門成果只保存在本機。進階探索保留原本的隨機房間、元素彈、化合物技能及排行榜。

- 兩種模式都可切換輔助戰鬥；預設開啟，只在敵人進入可攻擊範圍且沒有地形阻擋時自動普攻／射單箭，不自動消耗元素或 MP。
- [GA4：三款遊戲的實玩人數與入門漏斗](docs/GA4-games.md)

- 直接開啟 `chemistry_arpg.html`，或從首頁進入「元素獵人」。
- 鍵盤：方向鍵或 WASD 移動，Z 或空白鍵近戰，F 發射元素彈，C 切換已裝備技能，X 施放選中技能，1–4 直接使用技能。點擊元素欄切換彈藥。
- 手機：左側搖桿移動，右側圓鈕分別為普攻、技能與元素彈。點技能格只選招，再按技能圓鈕施放。
- 像素圖集位於 `assets/chem-arpg/`。若單獨搬移這個 HTML，請一併保留該資料夾的相對路徑；若圖片未載入，仍會顯示基本圖形。

## 開始遊玩

無需安裝任何依賴，直接用瀏覽器開啟 `index.html` 即可：

```bash
cd ai_game
open index.html          # macOS
# 或使用任意靜態伺服器
python3 -m http.server 8000
```

建議在手機瀏覽器使用「加入主畫面」功能，可獲得全螢幕沉浸式體驗。

## 技術

- 純前端靜態 HTML，所有 CSS/JS 內嵌於單一檔案
- 3D 魔術方塊使用 [Three.js](https://threejs.org/) (CDN r128)
- 化學俄羅斯方塊使用 Canvas 2D API
- Web Audio API 即時音效
- 響應式設計，適配手機直式與桌面橫式螢幕
