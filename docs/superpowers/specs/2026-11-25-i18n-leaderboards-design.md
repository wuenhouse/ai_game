# 三語介面與遊戲排行榜

使用者已確認：首頁與三款遊戲提供繁中、英文、日文；排行榜僅含俄羅斯方塊與元素獵人。結算後可輸入暱稱送出，或略過。俄羅斯方塊採既有分數；元素獵人死亡／擊敗 Boss 結算本次探索，一般怪 10、分子怪 30、Boss 100 分。

沿用靜態 HTML 與 Firebase Realtime Database 匿名登入。與後端驗證方案相比，前端送分容易部署、適合初步觀察，但不能保證成績真實性。每局紀錄僅玩家本人與管理者可讀；公開榜單每人每款最高分、前 20 名，暱稱跟隨該筆最高成績。身分依匿名帳號，清除瀏覽資料或換裝置視為另一位玩家。

語系依使用者選擇、瀏覽器偏好、繁中 fallback 決定；本地記住選擇，頁面內切換，不重開遊戲。介面與化學知識翻譯，元素符號、化學式與玩家留言／暱稱保留原文。

每局記錄分數、暱稱、遊玩時間、語系、版本、結束原因與角色。只在玩家按送出時登入與寫入；同一局使用固定 ID 防重複送出。新局重設探索分數，保留原有角色存檔邏輯。中途返回或重新整理不登錄。

規則限定兩款遊戲、本人寫入、合理型別／範圍／欄位及伺服器時間；歷史不可覆寫／刪除，最高分不可降低，歷史和榜單原子更新。不改既有留言規則。先本地驗收，部署與網站發布獨立回報；不自動 commit、push 或覆蓋正式規則。
