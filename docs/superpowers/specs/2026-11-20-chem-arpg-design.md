# 化學元素 ARPG 設計文件 — 「元素獵人」

> 日期：2026-11-20
> 狀態：已核准，待實作
> 格式：單一 HTML 檔案（CSS/JS 內嵌），Canvas 2D 渲染

## 1. 核心概念

俯視角即時動作 RPG。玩家在隨機產生的房間制地圖中探索與戰鬥，怪物掉落化學元素字母（H、O、C、Na、Cl、Ca），收集齊特定化學式可解鎖圖鑑、獲得大量經驗值並習得對應技能。角色等級與圖鑑跨遊戲永久保存於 localStorage，地圖每次重新隨機產生。

## 2. 地圖系統

### 2.1 房間制結構

- 每個房間固定 16×12 格（格子大小依螢幕自適應）
- 玩家走到房間邊緣時，畫面切換至相鄰房間
- 地圖為 5×5 網格（25 間房間）

### 2.2 房間類型

| 類型 | 數量 | 說明 |
|------|------|------|
| 起始房間 | 1 | 地圖中央，無怪物，安全區 |
| 一般房間 | ~20 | 隨機地形 + 2-5 隻怪物 |
| 寶箱房間 | 2-3 | 額外掉落元素，有守衛怪物 |
| Boss 房間 | 1 | 地圖邊緣，Boss + 稀有元素掉落 |

### 2.3 地形元素

- 牆壁（不可通過、不可破壞）
- 岩石（不可通過、可用攻擊破壞，可能掉落元素）
- 草叢（可通過、遮擋視線裝飾）
- 水池（不可通過）

### 2.4 房間生成規則

- 房間在玩家首次進入時生成，當次探索期間保留狀態
- 地形使用簡易隨機演算法：先填滿地板，再隨機放置牆壁/岩石/草叢（確保入口間有可通行路徑）
- 每次「出發探索」重新產生整張地圖

## 3. 戰鬥系統

### 3.1 近戰攻擊

- 朝面對方向揮擊，扇形範圍（角色前方 1.5 格寬）
- 攻擊判定持續約 150ms
- 冷卻 300ms

### 3.2 元素彈射擊

消耗背包中一個元素字母，發射直線遠程彈。不同元素有不同屬性：

| 元素 | 顏色 | 速度 | 傷害倍率 | 特殊效果 |
|------|------|------|---------|---------|
| H | 藍 | 快 | 0.6x | 無 |
| O | 紅 | 中 | 1.0x | 無 |
| C | 灰 | 慢 | 1.5x | 無 |
| Na | 紫 | 中 | 0.8x | 擊退 2 格 |
| Cl | 綠 | 中 | 0.8x | 持續傷害 3 秒 |
| Ca | 橙 | 慢 | 1.2x | 穿透（可命中多個敵人）|

### 3.3 化學式技能

合成化學式後解鎖為主動技能，消耗 MP 施放：

| 化學式 | 名稱 | MP 消耗 | 效果 |
|--------|------|---------|------|
| H₂O | 淨化之水 | 15 | 回復 30% 最大 HP |
| NaCl | 結晶爆破 | 20 | 周圍 3 格範圍傷害 |
| CO₂ | 煙霧彈 | 15 | 3 秒內周圍怪物停止追蹤 |
| NaOH | 腐蝕陷阱 | 25 | 放置陷阱，怪物踩到持續扣血 |
| CaCO₃ | 石盾 | 30 | 2 秒無敵 |
| CH₄ | 甲烷爆炸 | 40 | 大範圍高傷害（5 格半徑）|
| CaCl₂ | 急凍結晶 | 25 | 凍結周圍怪物 2 秒 |
| HClO | 酸霧 | 20 | 前方錐形持續傷害區域 3 秒 |

技能欄最多裝備 4 個技能。

## 4. 角色系統

### 4.1 屬性

| 屬性 | 初始值 | 每級成長 |
|------|--------|---------|
| HP | 50 | +10 |
| MP | 20 | +5 |
| ATK | 5 | +2 |
| SPD（移動速度）| 固定 | 不成長 |

### 4.2 經驗值來源

| 來源 | 經驗值 |
|------|--------|
| 擊殺一般怪物 | 10-20 |
| 擊殺 Boss | 100 |
| 首次合成化學式 | 200 |
| 重複合成化學式 | 50 |

### 4.3 升級公式

升到第 N 級所需累計經驗值：`N * N * 50`

## 5. 怪物設計

### 5.1 一般怪物 — 元素史萊姆

- 外觀：圓形色塊 + 元素符號文字
- 顏色對應元素（與元素彈相同配色）
- AI：偵測到玩家後朝玩家直線移動
- 擊敗後掉落身上顯示的元素字母（100% 掉率）
- HP 與傷害依玩家等級微幅縮放

### 5.2 分子怪

- 外觀：較大的圓形 + 化合物名稱
- 比一般怪物更強（HP 3x、ATK 2x）
- 掉落對應化合物所需的全部元素（例如 H₂O 怪掉 H、H、O）
- 每個房間最多出現 1 隻

### 5.3 Boss

- 外觀：大型方形 + 元素符號 + 閃爍邊框
- 攻擊模式：近戰揮擊 + 朝玩家發射元素彈
- 擊敗後掉落 3-5 個隨機稀有元素
- 每張地圖固定 1 隻

## 6. 圖鑑系統

- 列出所有 8 種可合成化學式
- 每個條目顯示：化學式、中文名稱、所需元素、對應技能說明
- 標記已收集（彩色）/ 未收集（灰色鎖定）
- 合成操作：在背包介面手動選擇元素，符合配方時顯示「合成」按鈕

## 7. 操作方式

### 7.1 鍵盤

| 按鍵 | 動作 |
|------|------|
| WASD / 方向鍵 | 移動 |
| Z / Space | 近戰攻擊 |
| X | 射擊元素彈 |
| C | 切換元素彈種 |
| 1-4 | 使用技能欄技能 |
| I / Tab | 開啟選單（背包/圖鑑/合成）|
| Esc | 關閉選單 / 暫停 |

### 7.2 手機觸控

- 左側：虛擬搖桿（移動）
- 右側：A 按鈕（近戰）、B 按鈕（射擊）
- 右上：當前元素指示器（點擊切換彈種）
- 技能欄：4 個小按鈕排列於右側
- 右上角：選單按鈕

- **狀態**：角色等級、經驗值、各項屬性

## 10. 遊戲流程

1. **標題畫面** → 「出發探索」/ 「圖鑑」/ 「角色狀態」
2. **出發探索** → 隨機產生 5×5 地圖，玩家從中央起始房間開始
3. **探索戰鬥** → 逐房間探索、戰鬥、收集元素
4. **合成** → 隨時可開選單合成化學式
5. **Boss 戰** → 擊敗 Boss 後顯示探索結算（經驗值、收集到的元素）
6. **死亡** → 失去當前地圖進度，保留等級與圖鑑，返回標題

## 11. 技術約束

- 單一 HTML 檔案，所有 CSS/JS 內嵌
- Canvas 2D 渲染，不使用外部函式庫
- 簡約幾何風格：圓形/方形 + 文字符號
- 深色主題，配色與現有化學遊戲一致
- Web Audio API 音效
- 目標 60fps，每房間最多 5 隻怪物以確保效能
