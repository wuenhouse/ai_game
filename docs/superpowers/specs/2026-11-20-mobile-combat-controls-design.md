# 手機戰鬥控制

依使用者要求直接完成一版可操作配置。

- 左手沿用移動搖桿；右手三個有文字的獨立圓鈕。
- 普攻位於左下、技能位於右上，兩者直徑 96px；元素彈位於右下，直徑 68px。
- 360px 以下採 88px 普攻／技能、64px 元素彈；技能格最小 44px 高。
- 四個技能格改為只選招，不扣 MP；技能圓鈕施放選招，顯示化學式及 MP 消耗。鍵盤 X 與數字鍵維持原施放功能。
- 元素彈圓鈕顯示目前彈種及剩餘數量；彈種沿用上方元素欄選擇。
- 未解鎖、MP 不足或彈藥不足時按鈕淡化，仍可點擊取得原因提示。
- 採 click 單一路徑啟動，避免 pointerdown 與 click 雙重施放；移動搖桿仍追蹤自己的指標。

## 驗證

- Node 17 項測試：鍵盤、搖桿、選招與單次施放、動作及留言回歸。
- 瀏覽器手機模擬 390×844 與 320×640：無水平溢出；320px 下四個技能格各為 44×44px，三圓鈕均在畫面內。
- 隔離測試頁：選第二技能不扣 MP，施放 NaCl 正好扣 20 MP，元素彈正好扣一個元素，普攻觸發攻擊計時器；未解鎖技能不改變選招。
- 瀏覽器持續拖曳搖桿時，以 DOM click 觸發技能仍可移動並施法；放開移動停止。尚未實機驗證雙指觸控。
- 隔離頁觀測工具只存在 /private/tmp，沒有加入正式遊戲。

## 桌面配置修正

- 依使用者回饋，非手機模式隱藏搖桿及三個戰鬥圓鈕，只保留置中的技能選擇列；桌面遊戲容器上限加寬至 1200px。
- 桌面新增 F 發射元素彈，避免隱藏按鈕後失去此功能；操作說明同步更新。
- 監聽 stage 尺寸變化重新計算畫布，涵蓋控制列切換與 HUD 換行。
- 1440×900 瀏覽器模擬驗證：圓鈕隱藏、控制列約 67px、畫布 976×732；F 正常消耗一個元素。390px 手機圓鈕仍顯示。
- Node 18 項測試通過；尚未實機驗證雙指觸控。
