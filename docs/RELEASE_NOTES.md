# 版本更新紀錄

本文件集中記錄化學益智遊戲實驗室的每次更版。後續更新請在最上方新增版本與日期，保留既有紀錄；尚未決定版本的變更先放在「未發布」區，再於更版時歸入正式版本。

每版記錄玩家看得到的新增功能、改善與修正、操作變更，以及實際完成的驗證。Git 分支推送、合併與網站部署是不同狀態；記入本文件不代表正式網站已更新。

## 未發布

- 預設輔助戰鬥，可從選角或選單關閉。不穿越地形、不代放技能或元素彈；弓手仍可手動蓄力。新增繁中、英文、日文任務、缺料提示及入門結算。
- 三款遊戲的原始頁面瀏覽保留，另區分有進入和實際遊玩、追蹤合成與再玩；元素獵人新增入門漏斗。詳見 [GA4 設定](GA4-games.md)。不改 Firebase 規則。
- 驗證：49 項 Node 測試，加上隔離的實際 Chromium 頁面驗收。法師以桌面鍵盤、弓手以手機尺寸與觸控完成入門並轉到進階；三款入口、俄羅斯方塊與魔術方塊的埋點均以瀏覽器驗證。未驗證手機實機、初次玩家局長、正式 GA4 收件或留存。

## v1.1.0 — 2026-11-25

- 首頁與三款遊戲加入繁中、英文、日文切換，依瀏覽器偏好預選並記住玩家選擇。包含動態提示、化學圖鑑、操作說明、留言介面與魔術方塊上的元素貼圖；玩家暱稱與留言保留原文。切換不重設遊戲。
- 俄羅斯方塊及元素獵人結算後可輸入暱稱、登錄分數或略過；各自顯示每位匿名玩家最高分前 20 名。魔術方塊暫不加入排行榜。
- 元素獵人新增本次探索分數：一般怪 10、分子怪 30、Boss 100 分，死亡或擊敗 Boss 結算，新探索歸零，角色永久存檔保留。
- Firebase 保存每次主動登錄的私有局次紀錄，包含分數、遊玩時間、語系、版本、結束原因與角色；公開榜單僅保留最高成績。新增不可覆寫與原子更新規則，兩款共用 5 秒送分冷卻。
- 畫布會隨語言文字換行及容器尺寸調整；修正手機魔術方塊畫布撐高、底部操作列被推到畫面外的問題。
- 補上送分逾時提示、保留暱稱重試、同局防重複及跨局慢速回應隔離。俄羅斯方塊開啟排行榜時暫停落下與鍵盤操作。
- 驗證：46 項 Node／DOM 測試、6 組 Firebase 官方本機規則驗收與瀏覽器隔離驗收通過，詳見 [驗收紀錄](i18n-leaderboards-validation.md)。本版依使用者要求提交並合併至 `main`；網站部署結果另行確認，正式 Firebase 排行榜規則尚未部署。前端送分不具完整防作弊能力。

## v1.0.2 — 2026-11-20

本版彙整合併至 `main` 的遊戲與討論區更新。網站部署狀態需另行確認；依另一個 Agent 的部署回報，新版 Firebase 隱私／分頁／冷卻規則已於 2026-11-20 部署至 `ai-game-82dd7` 並讀回確認，詳見 `firebase/README.md`。

### 新增

- 三款遊戲各有獨立意見與討論區，可匿名提問及回覆，透過 Firebase 共用資料，顯示最新 20 則主題並保留舊紀錄。
- 元素獵人開始畫面加入日系動畫／JRPG 冒險背景，桌面與手機各有對應構圖；搭配清楚的標題、探索按鈕、圖鑑與角色狀態入口。
- 桌面遊戲畫面右側常駐操作指南，直接顯示移動、攻擊、元素彈、技能與選單快捷鍵。
- 化學圖鑑改為可開啟獨立詳細視窗的知識卡片，加入 8 張化合物配圖、生活例子、元素組成／比例與來源連結；知識內容可先閱讀，遊戲技能仍需合成解鎖。

### 改善與修正

- 討論區新增主題／回覆分頁、跨遊戲共用的 30 秒發文冷卻、暫停發文開關及公開留言提醒；閱讀時不再建立匿名帳號。新版 Firebase 規則已部署；新版前端上線後需重新整理頁面，部署狀態詳見 `firebase/README.md`。
- 化學俄羅斯方塊與化學魔術方塊的回大廳按鈕統一採用元素獵人的文字、配色、圓角、44px 最小高度與鍵盤焦點樣式。
- 元素獵人開始畫面左上加入「回大廳」入口，手機保留獨立空間，避免遮住開始畫面內容。
- 近戰、元素彈與直接傷害技能命中怪物時加入約 0.12 秒硬直、短暫閃亮與小幅擊退；Boss 擊退較小，擊退會檢查地形，持續傷害不反覆觸發硬直。
- 修正桌面遊戲畫布被右側操作指南推偏：寬螢幕以左右等寬側欄讓畫布對齊視窗中央；較窄桌面將說明移至下方，避免擠壓遊戲區。
- 新增日系像素風怪物圖集，六種元素小怪、化合物怪與 Boss 各有不同外型；以程式疊上元素符號／化合物標記，保留原有戰鬥數值及掉落邏輯。
- 背包預設顯示六種遊戲元素的大字庫存卡片，完整 118 元素週期表改以獨立大視窗呈現，避免擠壓合成區；週期表高亮 H、O、C、Na、Cl、Ca 並顯示庫存，窄螢幕可橫向捲動。排列參考 IUPAC，符號及原子序核對 PubChem 官方資料。
- 圖鑑卡片改為開啟獨立詳細資料視窗；圖鑑及週期表可用返回按鈕、Esc 或點外側空白關閉，返回時保留原分頁與捲動位置，遊戲持續暫停。
- 統一背包、圖鑑、狀態與操作分頁的視窗尺寸，固定上方 Tab 與底部關閉按鈕，只讓中間內容捲動，避免切換時位置及按鈕大小跳動。
- 改善圖鑑、背包、角色狀態與操作說明選單：點擊視窗外的暗色空白區即可關閉並返回原畫面；點擊視窗內不會誤關閉。

- 修正手機搖桿顯示條件、縮放座標及指標追蹤；放開、觸控取消、失去焦點或切到背景時停止移動。
- 手機戰鬥控制改為左下普攻大圓鈕、右上技能大圓鈕及右下元素彈圓鈕。技能按鈕顯示選招及 MP 消耗，元素彈顯示彈種與數量。
- 點技能格改為只選招，再按技能圓鈕施放；未解鎖、MP 或彈藥不足時提供提示。
- 桌面隱藏手機圓鈕與搖桿，保留置中的技能選擇列；加寬遊戲區，並隨可用空間調整畫布尺寸。
- WASD 改依實體鍵碼判斷，修正中文輸入法回傳不同字元時無法移動的情況；新增 F 發射元素彈。
- 小地圖放大，桌面一般尺寸的房間格區為 130×130px，手機為 90×90px；加入地圖標題、半透明背景、外框及目前位置標示，狹小畫布會自動縮小。
- 更新角色高解析素材、步行及受擊動畫；碰撞怪物會向反方向擊退，並保留地形碰撞與護盾／無敵判斷。
- 留言介面拒絕空白暱稱與內容；Firebase 規則同步限制純空白、偽造身分、任意欄位、非法修改／刪除與不存在主題的回覆。

### 操作對照

| 動作 | 桌面鍵盤 | 手機觸控 |
| --- | --- | --- |
